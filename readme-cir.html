Chriz Item Randomiser

Author: Christopher Hermann (GitHub).
Built on: Item Randomiser by Fredrik Lindgren, also known as Wisp.
Version: 1.0.0 (in development, not yet released).
Languages: English; Polish game texts where Item Randomiser has them.

Overview

Chriz Item Randomiser (CIR) shuffles where items are found in Baldur's Gate, anew for each adventure you start. It works while you play, through EEex: each new adventure started in Baldur's Gate gets its own randomisation when its first character is accepted, and saves keep the randomisation they started with. You choose what is randomised in the configurator; changing those settings for the next adventure needs no reinstallation.

CIR is a new mod built on Wisp's Item Randomiser. It reuses that mod's item and location lists, item files and texts, and it cannot be combined with Item Randomiser's own randomisation (Mode 1 or Mode 2) or its “More Spell Shield scrolls” component; the configurator offers that option for each adventure instead. If one of them is installed after CIR, the configurator does not apply settings, and with Mode 1 or Mode 2 new adventures start only without randomisation.

Requirements

  • Baldur's Gate: Enhanced Edition Trilogy (EET). Other games are planned.
  • EEex with its LuaJIT component. Start the game with InfinityLoader.exe.

Installation

Extract the archive into the game folder so the cir folder is beside chitin.key. Supply a current WeiDU executable as setup-cir and run it. Install CIR after every mod that changes the user interface or the new-game template (UI.MENU, BALDUR.GAM).

The quest and conversation changes CIR relies on are made when it is installed and removed when it is uninstalled. They only take effect in adventures whose settings use them. If another mod changed one of those files so that the change cannot be made safely, the installer says so, leaves the file as it is, and the configurator does not offer what depends on it.

Configuration

Installing CIR changes nothing in play until a configuration is applied. After the whole mod stack is installed, close the game and use the configurator in cir/tools to scan the game and apply a configuration. The configurator currently requires Python 3.10 or later.

When a new adventure cannot be randomised (for example a start outside Baldur's Gate, or a game started without EEex), the game says why and lets you start it without the randomiser or cancel.

Uninstallation

Uninstalling CIR with WeiDU removes its runtime and its quest and conversation changes. Settings applied with the configurator are not recorded by WeiDU and stay in randomiser-campaigns. Adventures that were randomised may miss items after CIR is uninstalled.
